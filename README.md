# 픽셀편의점

밤 10시부터 아침 6시까지, 편의점 손님의 주문을 빠르게 맞추는 픽셀 웹게임입니다.

- 손님 말풍선에 나온 상품을 아래 진열칸 버튼으로 눌러 담으면 계산이 끝납니다.
- 손님이 기다리다 화가 나서 나가면 하트가 하나 줄고, 3개가 모두 없어지면 근무가 끝납니다.
- 시간이 지날수록 손님이 늘고 주문이 길어지며, 새 상품이 입고됩니다.
- 실수 없이 8명을 연속으로 받으면 하트를 하나 돌려받습니다.
- 아침 6시까지 버티면 퇴근 성공, 남은 하트만큼 보너스를 받습니다.

휴대폰 세로 화면에 맞춰 만들었고, 컴퓨터에서는 숫자키 1~8로도 상품을 고를 수 있습니다.

## 파일

- `index.html` 화면
- `js/sprites.js` 픽셀 그림(상품·손님·아이콘)
- `js/sound.js` 효과음
- `js/game.js` 게임 진행
